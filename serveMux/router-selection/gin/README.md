# gin

Web フレームワーク `Gin` を活用しつつ、標準ライブラリとの共存を図る構成案です。

## 特徴
- 独自の `gin.Context` を使用した、利便性の高い API 開発が可能です。
- 本サンプルでは、ビジネスロジック（ハンドラ）を標準の `http.HandlerFunc` で保ちつつ、Gin からブリッジして呼び出す手法を提示しています。
- これにより、フレームワークの利便性を享受しつつ、ハンドラの再利用性を確保しています。

## 実行方法
```bash
go run main.go
```

## 動作確認
```bash
# ヘルスチェック
curl http://localhost:8080/health

# ユーザー詳細 (Ginから標準ハンドラへのブリッジ確認)
curl http://localhost:8080/users/123
```
