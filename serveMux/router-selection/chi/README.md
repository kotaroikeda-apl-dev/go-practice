# chi

標準ライブラリとの互換性を重視した軽量ルーター `chi` による構成案です。

## 特徴
- `net/http` のインターフェースを完全に維持しており、標準ライブラリからの移行が容易です。
- `r.Route()` による階層的なルーティングにより、コードの構造化が可能です。
- `r.Use()` を使って、ミドルウェアを設定のようにフラットに記述できます。

## 実行方法
```bash
go run main.go
```

## 動作確認
```bash
# ヘルスチェック
curl http://localhost:8080/health

# ユーザー詳細 (パスパラメータの抽出確認)
curl http://localhost:8080/users/123
```
