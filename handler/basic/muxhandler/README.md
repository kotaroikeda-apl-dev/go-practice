# ServeMux.Handler によるハンドラの検査

このサンプルでは、`http.ServeMux` の `Handler` メソッドを使用して、リクエストにマッチするハンドラをプログラムから特定する方法を学びます。

## `mux.Handler(r *http.Request)` とは

`ServeMux.Handler` は、リクエストのメソッド、ホスト名、パスを元に、どのハンドラが実行されるべきかを特定し、以下の 2 つを返します。

1. **`h http.Handler`**: マッチした実際のハンドラ
2. **`pattern string`**: マッチした登録パターン（例: `"GET /users/{id}"`）

### 主な特徴（Go 1.22+）

- **リクエストを変更しない**: このメソッドはリクエストオブジェクトを変更しません。
- **PathValue はセットされない**: Go 1.22 から導入されたパスパラメータ（`r.PathValue`）は、このメソッドの呼び出し時点ではセットされません。これらは `mux.ServeHTTP` が呼び出された際にセットされます。
- **常に非 nil**: マッチするものがなければ、内部的な "404 page not found" ハンドラを返します。

## 実行方法

1. サーバーを起動します。
   ```bash
   go run handler/basic/muxhandler/main.go
   ```

2. ブラウザまたは `curl` でアクセスします。
   ```bash
   curl http://localhost:8080/users/42
   ```

3. ターミナルの出力を確認します。どのパターンにマッチしたか、また `r.PathValue` がどのタイミングでセットされるかが確認できます。

## コードのポイント

```go
// マッチするハンドラとパターンを特定する
h, pattern := mux.Handler(r)

// この時点ではパスパラメータはまだ取得できない
id := r.PathValue("id") // "" になる
```

このメソッドは、ミドルウェアなどで「どのハンドラが実行されるか」に基づいて処理を分岐させたい場合（例：特定のパスパターンのときだけ認証をスキップする、など）に非常に有用です。
