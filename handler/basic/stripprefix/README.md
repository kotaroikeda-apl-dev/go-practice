# http.StripPrefix サンプル

このサンプルでは、Goの標準パッケージ `net/http` に含まれる `http.StripPrefix` 関数の使い方を説明します。

## StripPrefix とは？

`http.StripPrefix` は、HTTPリクエストのURLパスから指定したプレフィックス（接頭辞）を取り除いた後、別のハンドラに処理を引き継ぐための「ミドルウェア」のような役割を果たす関数です。

### 主な特徴

- **パスの加工**: 指定した文字列をパスの先頭から削除します。
- **404エラー**: リクエストされたパスが指定したプレフィックスで始まらない場合、自動的に `404 Not Found` を返します。
- **よくある用途**: 静的ファイル（画像、CSS、JSなど）を `/static/` のようなパスで公開しつつ、実際のディレクトリ構造には `/static/` が含まれない場合などに便利です。

## 実行方法

```bash
go run handler/basic/stripprefix/main.go
```

## 動作確認

サーバーを起動した後、以下のURLにアクセスして動作を確認してください。

1. **プレフィックスが一致する場合**:
   - URL: `http://localhost:8080/tmp/hello`
   - 結果: 最終的なハンドラには `/hello` というパスが渡されます。

2. **プレフィックスが一致しない場合**:
   - URL: `http://localhost:8080/other`
   - 結果: `404 page not found` が返されます（`DefaultServeMux` に他のハンドラが登録されていないため、または `StripPrefix` が一致しないため）。

3. **プレフィックスそのもの**:
   - URL: `http://localhost:8080/tmp/`
   - 結果: 最終的なハンドラには `/` というパスが渡されます。
