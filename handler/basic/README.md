# http.Handler の基本

このディレクトリでは、Go の HTTP ハンドラの 2 つの主要な実装方法について学びます。

## サンプル一覧

### 1. [Handler (構造体スタイル)](./handler/)

構造体に `ServeHTTP` メソッドを実装する方法です。
状態（設定や DB 接続など）を持ちたい場合に適しています。

### 2. [HandlerFunc (関数スタイル)](./handlerfunc/)

`http.HandlerFunc` アダプターを使用して、普通の関数をハンドラとして扱う方法です。
シンプルな処理を記述する場合に適しています。

### 3. [StripPrefix](./stripprefix/)

リクエスト URL から特定のプレフィックスを削除して別のハンドラに渡す方法です。
静的ファイルの配信などに便利です。

### 4. [TimeoutHandler](./timeouthandler/)

ハンドラの処理にタイムアウトを設定する方法です。
遅いリクエストによってサーバーリソースが占有されるのを防ぎます。

### 5. [MaxBytesHandler](./maxbyteshandler/)

リクエストボディのサイズを制限する方法です。
巨大なリクエストによるリソース枯渇を防ぎます。
